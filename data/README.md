# 案例语料与许可边界

本目录存放可复现案例所需的结构化语料，不包含用户本机数据库、项目备份或 API Key。

## 《山海经》语料

`shanhai-corpus.zh-hans.json` 的内容分为四类：

1. 《山海经》古籍原文本身属于公有领域。
2. 原典电子转录来自维基文库，按 CC BY-SA 4.0 使用；文件中保留了具体页面、修订号和修订时间，作为署名与可追溯记录。
3. 白话今译、编排说明和项目复核字段由 Worldcraft Codex 项目整理，不复制现代网站译文。
4. `shanhaijing.5000yan.com` 仅作为信息架构与阅读体验参考；其现代译文不进入语料或重制版 Wiki 正文。

中国哲学书电子化计划用于异文交叉核对。源文件中的来源 URL 只服务于构建审计，不会被导入“山海经 · 原典内容全集重制版”的软件内 Wiki；严格案例审计会阻止第三方 Wiki 痕迹或外部链接进入该重制版。

## 原创内容

本项目新增的故事化改编、情节连接和创作提案必须在软件内标记为“项目原创”或“创作改编”，不得冒充传统文献记载。资料性说明应区分原典原文、现代释读、学术不确定性与项目创作。
