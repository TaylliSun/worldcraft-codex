# Worldcraft Codex 1.8.0-beta.1

## AI 项目操作层

- 新增“项目操作”工作区，内置 AI 可直接创建、更新和删除条目、任务、剧情变量、剧情场景、关系、时间轨道与时间点。
- 支持一次指令跨模块创建对象，并通过批次引用自动连接新角色、任务、场景、关系和时间点。
- 不要求逐项确认。模型返回后立即执行本地字段白名单、引用与结构校验，全部通过才以单次 SQLite 事务写入。
- 每次执行前自动创建专用检查点，并在“最近操作”中保存指令、模型、摘要和受影响对象。
- 支持一键撤销完整批次；若受影响对象后来被作者手动修改，会阻止覆盖式撤销。
- 操作记录随项目保存、备份和导出；合并导入时转为只读归档记录。

## 数据与隐私

- 项目数据库升级到 schema 14，新增 `aiOperationRuns` 对象集合。
- AI 项目上下文按模块分配字符预算，不发送条目正文、模板自定义数据、模板秘密字段或任务开发者备注。
- schema 8 至 13 的六条升级路径均保留对象哈希、搜索索引和迁移前数据库副本。

## 验证

- AI 操作核心覆盖解析、七类对象、跨对象引用、失败原子性、冲突保护、同对象多步折叠与完整撤销。
- Electron E2E 覆盖无确认直接执行、自动检查点、五模块持久化、精确跳转、重启和一键撤销。
- 已验证 1440×900 与 1100×780 窗口，无页面级横向溢出。
