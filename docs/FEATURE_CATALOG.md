# Worldcraft Codex 功能目录

Worldcraft Codex 是一个本地优先的游戏剧情与世界观开发软件，用来管理游戏项目里的世界观、角色、地点、组织、物品、事件、任务线和分支剧情。

当前 `2.2.0-rc.24` 已形成长篇文稿、分镜预演、稳定引用、出版导出、批注修订、写作节奏与分层 AI 写作闭环，并补齐公开发布边界：Windows 安装版支持稳定/候选更新通道、显式下载与重启安装，发行门禁会检查签名输入、第三方许可证、SBOM、依赖漏洞、秘密、SHA-256 清单和构建来源；候选包不会伪装成已签名正式版。

- 创建游戏项目/世界

- 在摘要、正文、模板长文本、任务步骤和剧情文本旁直接调用统一 AI，无需离开当前编辑位置
- 对光标或选区执行续写、改写、压缩、扩展、语气调整、一致性修正和定点修复，并在应用前显示差异
- 查看本轮实际使用的项目来源与长期记忆，固定、排除或调整来源优先级；无来源内容明确标记为新创作
- 将 AI 提取的新事实保存在候选草稿记忆中，不会自动冒充作者确认的正式设定
- 在写入前后运行本地一致性预检；新增严重或主要问题时显示详情并要求作者再次确认
- 每次字段级 AI 修改都保存精确原值、富文本值、来源和检查点，可在字段未被继续编辑时完整撤销

## 数据说明

当前版本运行在 Electron 桌面窗口中，主数据保存在系统用户数据目录里的 SQLite 数据库：

- Windows 默认位置通常在 `%APPDATA%\worldcraft-codex\worldcraft-codex.sqlite`
- 快速数据快照和完整工程备份位于 `%APPDATA%\worldcraft-codex\backups`
- 数据库迁移保护副本位于 `%APPDATA%\worldcraft-codex\backups\migrations`
- 迁移回滚前的安全副本位于 `%APPDATA%\worldcraft-codex\backups\rollbacks`
- 导入的资源文件位于 `%APPDATA%\worldcraft-codex\assets`
- 项目可另存为自包含 `.wcodex` 工程包；旧 `.wcodex.json` 仍可打开，但不包含资源二进制

当前路线不包含游戏引擎专用导出、公开社区、实时多人协作和插件市场。AI 接口默认关闭，不提供通用聊天，也不会在后台自动向外部服务发送项目内容。

发布、隐私和恢复资料见 `docs/`。
