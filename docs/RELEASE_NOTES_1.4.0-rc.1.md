# Worldcraft Codex 1.4.0-rc.1 Beta

这是首个以可发布稳定性为核心的候选版本，功能范围冻结在本地游戏剧情、任务线、角色与世界资料生产闭环。

## 本次新增

- 新增脱敏启动日志、渲染器错误捕获和一键诊断包。
- 新增 schema 8、9、10 到 11 的迁移矩阵、保护副本及回滚再升级验证。
- 新增数据库锁定、只读、写入失败、连续自动保存、损坏对象与缺失资源测试。
- 新增真实 Electron E2E，覆盖首次启动、导航、模板、资料台账、叙事制作、搜索、正常退出和异常退出恢复。
- 同时提供 Windows x64 便携版与 NSIS 安装版；卸载默认保留用户数据。

## 升级说明

启动时会自动检查并升级旧数据库，升级前在 `backups/migrations/` 生成保护副本。建议升级前另存一份 `.wcodex.json`，升级后在“检查”视图确认 `quick_check: ok`。

## Beta 提醒

本候选版尚未使用可信代码签名，可能触发 Windows SmartScreen。请先阅读 `KNOWN_LIMITATIONS.md` 和 `BACKUP_AND_RECOVERY.md`，并为重要项目保留异盘备份。
