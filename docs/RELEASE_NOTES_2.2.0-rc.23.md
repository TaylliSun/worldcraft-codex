# Worldcraft Codex 2.2.0-rc.23

`2.2.0-rc.23` 是 Windows x64 候选版。本版把剧情场景从文字节点扩展为可携带图片或视频的分镜，并加入面向编剧、叙事设计与演示录制的连续预演工作台。

## 本版变化

- 剧情场景可关联资源库中的图片或视频，并可在节点内直接导入新素材。
- 每个场景可设置镜头景别、时长、转场和运镜说明，旧工程会自动补齐兼容默认值。
- 新增分镜时间带，可按剧情顺序浏览镜头并直接定位到对应节点。
- 新增剧情预演：支持播放、暂停、下一镜和分支停顿，图片与视频均可进入预览画面。
- 视频资源成为正式资源类型，支持 MP4、WebM、MOV 和 MKV 的导入、预览、工程打包与跨机器迁移。
- 删除被场景使用的资源前会显示引用数量；复制世界与导入工程时会同步重映射分镜资源引用。
- 场景媒体进入反向引用索引、公开副本清理与 AI 上下文，避免素材在编辑、发布或 AI 修改时失联。
- 调整分镜工作台的桌面与窄窗口布局，媒体、台词和控制区保持清晰且不产生横向溢出。

## 兼容性

- 现有 `2.2.0-rc.22` 工程可直接升级，未设置分镜信息的剧情节点按默认镜头参数载入。
- `.wcodex` 完整工程包会保留场景引用的本地图片和视频；JSON/Markdown 交接格式仍不包含资源二进制。
- 当前仍为未签名候选版，Windows 可能显示未知发布者提示。
