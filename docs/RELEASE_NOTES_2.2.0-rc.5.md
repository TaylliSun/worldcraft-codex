# Worldcraft Codex 2.2.0-rc.5

## 世界脉络与关系星图

- 全局关系图升级为“脉络”布局，角色、组织、地点、事件、物品和笔记拥有独立色轨、图标与数量标记。
- 新增“星图”布局：当前条目成为深色中央核心，直接邻居按关系轨道环绕分布。
- 邻居较多时自动扩展为多层椭圆轨道，并按条目类型、关系数量和名称稳定排序，减少节点重叠。
- 星图连线会按节点边界计算起止点，以柔和曲线保留方向箭头、强度线宽、关系标签和点击选择。
- 星图节点显示条目类型，核心节点用独立金色边框与深色卡片强调，不影响搜索、筛选、缩放、拖拽和全屏详情。
- 画布增加主次网格，详情栏与关系端点补充视觉标识，同时保持紧凑的工作台密度。

## 验证

- Next.js 生产构建与 TypeScript 检查通过。
- Electron 桌面回归通过 `120` 项断言，新增验证星图模式与轨道画布，并继续覆盖搜索、缩放、拖拽、全屏详情及正常 / 异常重启恢复。
- 数据库 schema 保持 `16`，可直接读取此前项目。
