# G4 桌面质量基线

适用于 Worldcraft Codex `2.2.0-rc.1` 的发布候选收口。本文记录 2026-07-13 完成的性能、首次启动、桌面交互、升级安装与发行物门禁。

## 大型项目性能预算

基准数据集包含 1 个世界、10,000 个设定条目、400 条任务和约 399 万个 JSON 字符，使用正式 schema `16`、真实 `WorkspaceStore`、SQLite FTS 与项目引用索引。

| 工作流 | 发布预算 | 本机实测 |
| --- | ---: | ---: |
| 首次保存 10,401 个对象 | 8,000 ms | 1,849 ms |
| 冷加载项目 | 3,000 ms | 99 ms |
| 构建跨模块引用索引 | 4,000 ms | 199 ms |
| 侧栏筛选 10,000 个条目 | 1,000 ms | 50 ms |
| 切换查找 500 个对象 | 500 ms | 51 ms |
| 单对象增量保存 | 1,500 ms | 262 ms |
| SQLite 全文检索 | 750 ms | 2 ms |

运行命令：`npm run test:performance`。预算是发布门禁，不应因单次失败直接放宽；需先排查实现、测试环境和性能回退。

项目树默认折叠分类，折叠分支不创建条目 DOM；展开后每批显示 120 个条目，并保留当前选中条目。搜索输入使用 React 延迟值，避免键入被大列表同步计算阻塞。

## 首次启动

空数据库不再直接落入功能密集的样例界面，而是先提供四个可直接开工的起步包：

| 起步包 | 默认内容重点 |
| --- | --- |
| 游戏叙事 | 角色、地点、阵营、主线任务与可测试剧情 |
| RPG 战役 | 冒险小队、据点、委托人与阶段任务 |
| 视觉小说 | 角色路线、章节场景、好感变量与选项 |
| 开放世界任务 | 区域据点、阵营声望、探索线索与任务链 |

每个起步包都会创建可编辑条目、至少两步任务、剧情场景、变量和叙事里程碑，并在一次 SQLite 保存后进入创作台。首次启动不可意外关闭；从世界设置创建新世界时可以取消。定义测试由 `npm run test:starter-packs` 覆盖，Electron E2E 还会实际创建视觉小说项目并重启读取任务、场景和变量。

## 键盘、焦点与中文输入

共享弹窗焦点管理覆盖统一创建、分类编辑、全局搜索、字段级 AI 和起步包选择：

- 打开后聚焦主要输入项。
- `Tab` 与 `Shift+Tab` 保持在当前模态弹窗内。
- `Esc` 关闭可关闭弹窗，并把焦点还给触发按钮。
- 首次启动起步包不响应 `Esc`，防止进入未初始化状态。
- `KeyboardEvent.isComposing` 为真时，不执行 Enter 提交、Esc 关闭或 `Ctrl/Cmd+K` 快捷键。
- 世界设置完成选择后立即收起，并把焦点还给设置按钮，避免浮层遮挡其他工作区。

`npm run test:e2e` 当前覆盖 104 条断言和 3 次 Electron 启动，包括上述焦点与输入法行为、1100 x 780 窗口无横向溢出、自动备份有效性、正常退出排空保存队列、正常重启和异常退出恢复。

## 安装与升级

- 解包应用在全新目录报告版本 `2.2.0-rc.1`、schema `16` 和 `quick_check=ok`。
- 便携包装器冷启动约 13.1 秒，依次记录 `app.starting`、`database.opened` 和 `window.ready`；运行中和测试终止后数据库均通过 `quick_check`。
- NSIS 自动化先安装 `2.1.0-beta.1`，写入唯一世界、条目标记和手动备份，再覆盖安装 `2.2.0-rc.1`。
- RC 读回相同世界 ID、条目 ID、正文标记与有效备份，随后静默卸载；应用目录被删除，用户 SQLite 与备份保留。
- 升级门禁在开发中发现并修复了备份列表把有效备份误标为损坏的问题，Electron E2E 已增加永久回归断言。

## 当前结论

大型项目性能、四类起步包、键盘焦点、中文输入法、覆盖升级、卸载保留和最终发行物均已达到 G4 RC 基线。当前剩余公开分发约束是缺少可信代码签名证书，并需要经过 RC 使用期继续收集真实项目反馈。

本阶段不增加社区、插件市场、实时协作或游戏引擎专用导出。
