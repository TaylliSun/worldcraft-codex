# Worldcraft Codex 2.2.0-rc.22

`2.2.0-rc.22` 是面向 2026-07-31 现场展演的 Windows x64 候选版，重点是演示可靠性、界面收口、正式案例完整性和安全分发边界。

## 本版变化

- 窄窗口中的条目检查栏不再覆盖编辑器工具栏，关闭按钮保持可见、可点击。
- Electron 回归新增真实命中检测，防止按钮虽然存在却被浮层拦截。
- 世界切换器直接显示每个世界的条目、地图和章节数量，大型案例更容易辨认。
- 小说书稿在桌面与窄窗口中采用固定工作台，页面不再与正文编辑区同时出现纵向滚动条。
- 资源库消除外层页面的多余滚动，只保留资源详情面板自身的滚动区。
- 新增只读 `demo:check`，核验 SQLite、schema、两个主案例规模、山海经物理资源和外部链接边界。
- 新增 `demo:open`，预检通过后再启动桌面软件。
- 自动录屏脚本必须使用独立数据目录，并拒绝正式用户目录或异常庞大的演示数据库。
- 主题与 Wiki 的 Electron 回归默认加载生产构建，不再依赖本地开发服务器。
- Next.js 升级到 `16.2.12`，并锁定已修复的 PostCSS 与 sharp 版本；生产依赖审计为 0 个已知漏洞。
- 升级安装测试会等待应用文件与卸载注册项都完成清理，消除 NSIS 异步收尾造成的偶发误报。
- 补充展演路线、故障备用流程、GitHub 首页、提交排除规则与签名公开版手动工作流。

- 山海经重制版 284/284 个物理资源可用，外部链接与第三方 Wiki 痕迹均为 0。
