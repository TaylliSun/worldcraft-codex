# Worldcraft Codex 2.2.0-rc.9

## 大型关系网络

- 脉络默认从当前条目的直接关系开始，不再一次性铺开整个世界。
- 新增“当前直接关联 / 二度上下文 / 全部网络”三级范围，可在局部追踪与全局浏览之间切换。
- 每种条目默认按优先级显示最多 `8` 个；当前条目、关系距离、直接关系强度和连接数量共同决定排序。
- 超出上限时，类型轨道显示“当前数量 / 总数”，底部提供分批展开与收起操作；搜索选中的条目始终优先保留。
- 自动适配在脉络模式下不会低于 `75%`，避免大型网络被缩成无法阅读的小字，仍可手动继续缩放和拖动画布。

## 线路降噪

- 跨越中间类型列的长关系改走节点上方通道，不再穿过其他国家、角色、物品或组织节点。
- 长关系按稳定哈希分配到四条通道，数据刷新后线路位置保持稳定，并减少多条关系完全重叠。
- 二度与全部网络中，非当前核心关系进一步降低视觉权重；悬停或选择后仍可恢复清晰显示。
- 关系类型图例继续支持单独隐藏敌对、控制、位置、路线等关系，和范围控制共同用于大型项目降噪。

## 验证

- Next.js 生产构建与 TypeScript 检查通过。
- Electron 桌面回归通过 `139` 项断言，覆盖直接 / 二度 / 全部范围切换、跨列路径通道、星图分环、保存恢复与三次应用启动。
- 发布诊断通过 `28` 项断言；便携版冷启动通过 `11` 项断言，SQLite `quick_check` 为 `ok`，数据库 schema 保持 `16`。
