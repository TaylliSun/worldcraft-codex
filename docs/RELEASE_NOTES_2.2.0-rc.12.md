# Worldcraft Codex 2.2.0-rc.12

## 地图 2.0：专业交互画布

- 地图工作区支持全屏专注模式，左右目录与检查器可独立折叠，在小屏和复杂地图中保留更大的编辑空间。
- 画布按地图原始尺寸渲染，支持鼠标拖动画布、滚轮定点缩放、缩放按钮、自动适配与定位当前标记。
- 新增缩略导航图，同时显示标记、路线与当前可视区域；点击缩略图可快速跳转。
- 标记图标在不同缩放级别下保持可点击尺寸，避免放大后过大或缩小后无法操作。

## 标记编辑与安全

- 标记可直接拖动，移动期间实时预览关联路线，松开后仅保存一次，减少数据库写入和历史噪声。
- 选中标记后可使用方向键微调；普通步长为 `0.25%`，按住 `Shift` 时为 `2%`。
- 地图工具栏支持标记移动撤销与重做，保留最近 `100` 次移动记录。
- 锁定图层或标记组后，其标记仍可选择和查看，但不能被拖动或键盘误移。

## 大型地图降噪

- 标签会根据缩放级别自动降噪；当前选中的标记始终保留标签，也可从工具栏手动切换全部标签。
- 低缩放级别下，同一区域内 `3` 个及以上标记会形成聚合点；点击聚合点可放大并定位该区域。
- 全屏模式包含键盘焦点约束，`Esc` 会优先取消放置状态，再退出全屏。
