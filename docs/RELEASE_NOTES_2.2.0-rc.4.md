# Worldcraft Codex 2.2.0-rc.4

## 世界关系工作台

- 关系图改为常驻工具栏与独立画布布局，日常页面和全屏模式保持一致操作。
- 新增图内条目搜索与结果定位，可在“全局”和“聚焦”视图间快速切换。
- 支持空白画布拖拽平移、`Ctrl + 滚轮`缩放、按钮缩放、自动适配全部内容和定位当前条目。
- 关系类型图例支持逐类显示或隐藏，关系标签也可整体收起；非当前邻域的标签自动减少，降低连线交叠。
- 节点双击可直接打开对应设定条目，键盘方向键、加减号与数字 `0` 可控制画布。
- 全屏新增条目/关系详情栏；节点显示摘要和相关关系，连线显示端点、方向、类型、强度与备注。
- 全屏可直接打开条目，或返回原关系编辑器继续修改选中的关系。
- 窄窗口下工具栏自动换行，全屏详情栏转为纵向布局，避免控件与文字挤压。

## 验证

- Next.js 生产构建与 TypeScript 检查通过。
- Electron 桌面回归通过 `119` 项断言，覆盖关系图搜索、聚焦、缩放、适配、拖拽、标签显隐、全屏详情及正常 / 异常重启恢复。
- 数据库 schema 保持 `16`，可直接读取此前项目。
