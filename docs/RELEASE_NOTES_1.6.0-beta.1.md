# Worldcraft Codex 1.6.0-beta.1

本版本新增持久化 AI 剧情写作室，重点解决长线创作中的连续性、版本保险和精确修改定位。

## 深度剧情写作

- 一键执行“策划 → 正文 → 连续性审校”，也可单独重跑任一阶段。
- 写作目标、文风、硬约束、提纲和正文持续保存在项目中。
- 写作目标可指向设定条目、任务线或剧情场景，完成后明确追加到对应项目位置。

## 长期记忆

- 审校自动提取世界事实、角色状态、剧情进展、创作规则和未解线索。
- 自动记忆先标记为草稿，作者可确认、编辑、置顶或删除。
- 后续写作根据目标、提纲和正文检索相关记忆；作者确认、置顶和同目标记忆优先。
- 每轮保存实际使用的记忆快照，便于追查模型当时依据了哪些信息。

## 修改定位与保险

- 审校建议必须逐字引用当前草稿中存在的原句。
- 点击“定位”会选中原文位置，点击“应用”只替换对应片段。
- 每次策划、正文和审校自动保存写作轮次，支持手动检查点和历史版本恢复。
- 写作会话和记忆进入 schema 12 SQLite、对象历史、项目备份和完整项目导出。

长期记忆可以降低遗忘并提供恢复依据，但不能突破模型本身的上下文长度；关键设定仍应由作者确认。
