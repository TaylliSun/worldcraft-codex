# 已知限制

- `2.2.0-rc.21` 是 Windows x64 Release Candidate，尚未提供 macOS、Linux 或 ARM64 发行物，也不代表最终稳定版。
- 当前发行物没有可信代码签名证书，Windows SmartScreen 可能显示未知发布者；正式公开分发前需要外部证书签名。
- NSIS 安装版已具备稳定/候选更新通道、显式下载和重启安装；当前候选包没有真实 HTTPS 更新源，因此不会发起更新请求。便携版不自动更新，仍需保留用户数据并手动替换程序文件。
- NSIS 采用每用户单击安装以保证静默升级路径稳定，不提供安装目录选择；需要自定义位置时使用便携版。公开构建的法律条款在应用首次启动时确认。
- 安装与应用内更新要求系统盘至少有 2 GiB 可用空间；空间不足时不会启动下载或安装，需释放空间后重试。
- 便携版每次启动前会自解压到 Windows 临时目录，也需要约 2 GiB 临时空间；解压发生在应用启动前，空间不足时无法显示应用内提示。
- 自动更新不会为失败版本提供服务端强制降级；安装失败时现有版本与项目数据保持不变，回退应使用已保留并签名的上一版安装包。
- 单机单用户写入，不支持实时多人协作、云同步或冲突合并。
- 不包含公开社区、插件市场、通用聊天和游戏引擎专用导出。
- JSON/Markdown 是经过秘密隔离的发布交接格式，不是无损项目备份，也不会直接生成 Unity、Unreal、Godot 的运行时资源；跨机器完整恢复应使用 `.wcodex` 工程包。
- `.wcodex` 会包含项目正文、秘密字段、AI 私有记忆和本地资源，未加密，不应作为公开发布文件；API Key 不会进入工程包。
- 旧 `.wcodex.json` 和快速数据快照不包含资源二进制，只适合数据回滚；完整工程备份和手动另存的 `.wcodex` 才包含资源。
- 删除世界会先创建完整 `.wcodex` 备份并移除该世界的数据库记录，但不会自动删除其本地资源文件；这样可避免共享文件或误删造成不可逆损失，磁盘整理仍需用户在资源确认后手动进行。
- 工程包采用流式 ZIP64 读写，但实际可处理规模仍受目标磁盘剩余空间、单文件系统限制和杀毒软件实时扫描影响。
- 超大图片、音频库或超长富文本仍受本机内存、磁盘和 GPU 驱动影响。
- AI 工具支持本地或第三方 OpenAI-compatible Chat Completions 接口；不直接适配只提供其他专有协议的服务。
- 流式长文生成会优先使用兼容的 SSE 响应；不支持流式的兼容服务仍会在完整响应返回后显示结果，取消只能中止尚未完成的请求。
- 第三方模型的可用性、计费、内容保留和地区政策由对应服务商负责，Worldcraft Codex 不代理请求。
- AI 生成文本仍可能存在事实错误；AI 项目操作会在结构校验后直接写入，执行前自动创建检查点并提供完整撤销，一致性核心规则不依赖模型结果。
- 编辑器内 AI 会显示实际来源、候选事实和修改前后的一致性结果，但这些保护不能证明模型输出绝对正确；作者仍应审阅事实、语气和叙事意图。
- 字段级撤销只在目标字段仍与 AI 写入值完全一致时执行；作者后续手工修改过该字段时会停止撤销，以免覆盖新内容。
- AI 项目操作当前覆盖世界设置、项目分类、条目模板、条目、任务、剧情变量、剧情场景、测试预设、审阅问题、关系、资源元数据、成员权限、地图、图层、标记组、标记、路线、区域、叙事里程碑和时间线；资源二进制与路径、自动生成的测试运行结果、一致性扫描记录和凭据保持只读。
- 长期记忆、相关性检索和写作轮次能显著降低跨章节遗忘并允许恢复，但不能突破第三方模型本身的上下文长度，也不能保证模型永不出错。
- 自动提取的记忆默认是“草稿记忆”，重要设定应由作者确认或置顶；发生冲突时提示词要求优先采用作者确认记忆。
- 自动冲突检测只比较填写了主语、属性、值和相同生效范围的结构化事实，以及作者明确建立的矛盾关系；未结构化的自然语言仍需要作者审校。
- “忽略差异”按当前两条记忆的确定性冲突标识保存；删除并重建其中一条记忆后可能再次出现提示。
- 长篇文稿可导出 DOCX、PDF 与 EPUB，但当前定位是可交付书稿和电子书初稿，不包含脚注/尾注、自动页码目录、孤行寡行控制、印刷色彩管理或出版社专用模板；最终纸书仍建议进入专业排版软件校样。
- 批注修订按引用原文精确定位；作者先行改写了引用句时，建议会标记为失效并停止自动替换，需要重新选择原文。
- 写作节奏记录每天第一次正文变更前与当前全书字数的净差，不统计键盘活动时长，也不会把删除再重写的全部过程累计成虚高产量。
- AI 语义召回使用完全本地的概念别名、文本片段和结构化事实相似度，不下载嵌入模型，也不是通用向量数据库；罕见术语、跨语言隐喻和未结构化长距离关联仍可能需要作者标签、确认或置顶。
