# Worldcraft Codex 2026-07-31 展演手册

这份流程以“现场稳定、无需联网、八分钟讲清产品价值”为目标。正式项目数据库只读预检，不运行自动备份，不在台上删除或复制大型世界。

## 展演前 15 分钟

1. 连接电源，关闭系统更新、聊天弹窗和无关窗口。
2. 使用 1920×1080、100% 或 125% 缩放；确认投影画面没有裁掉软件右侧。
3. 至少保留 2 GiB 系统盘空间。当前正式备份目录较大，展演期间不要创建完整备份。
4. 在项目目录运行：

```powershell
npm run demo:check
```

5. 看到“预检通过，正式数据未被修改”后运行：

```powershell
npm run demo:open
```

6. 提前打开 `中国上古神话史` 的 Wiki 首页，确认搜索、世界切换和地图专注模式可用。
7. AI 仅在模型连接已提前验证时现场生成；否则展示已保存的写作会话、来源和长期记忆。

## 八分钟主路线

### 0:00 - 0:45 产品定位

从作者工作台开始：Worldcraft Codex 是本地桌面创作工程，不是网页原型。世界、小说、任务、地图和 AI 共享同一组可追踪对象。

### 0:45 - 2:15 世界 Wiki

1. 从顶栏世界菜单切换到 `中国上古神话史`。
2. 指出菜单会先显示每个世界的条目、地图和章节规模。
3. 打开世界总览，展示目录、最近更新和 2,442 篇条目规模。
4. 搜索“观音”或“女娲”，进入文章；将鼠标停在绿色内部链接上，展示即时资料卡。

讲述重点：编辑资料会自动成为软件内可阅读的 Wiki，不需要另做发布页面。

### 2:15 - 3:30 关系与时间

1. 打开关系图，切到星图，再进入全关系图谱。
2. 展示不同关系强度、节点筛选和条目跳转。
3. 打开时间线，说明神圣叙事、文献证据、宗教制度和信仰演变可以分轨记录。

讲述重点：关系和年代不是正文里的死文字，而是可检查、可导航的数据。

### 3:30 - 5:20 山海经地图

1. 切换到 `山海经 · 原典内容全集重制版`。
2. 打开地图并进入专注模式。
3. 展示主地图、子地图、图层栏、独立异兽图片、区域边界和路线。
4. 用滚轮缩放，在黑色无限画布区域平移；选择图片图层，展示移动、缩放和旋转控件。

讲述重点：底图不是边界，作者可以像轻量图层软件一样持续扩展地图。

### 5:20 - 6:35 长篇正文

1. 打开剧情 > 正文。
2. 选择任一《山海经》章节，进入正文全屏模式。
3. 展示书、卷、章、场景结构，以及批注、版本、伏笔和人物知识状态。

讲述重点：软件既能写设定，也能直接承载第一章、第二章式的长篇创作。

### 6:35 - 7:35 AI

1. 打开 AI 剧情写作。
2. 展示本轮召回的来源、长期记忆和事实冲突提示。
3. 演示定位修订：建议引用原句，作者只应用指定位置。
4. 若网络和模型稳定，再执行一次短续写；否则停留在已保存结果。

讲述重点：AI 不靠一段无限增长的聊天记录记忆项目，而是从结构化世界、原文来源和作者确认事实中召回。

### 7:35 - 8:00 收束

回到作者工作台：所有内容保存在本地 SQLite，可导出完整 `.wcodex` 工程包；当前产品不做社区和插件市场，重点是单机创作闭环。

## 现场备用路线

- **模型不可用**：展示已有 AI 会话、来源、记忆和撤销记录，不重试长生成。
- **地图加载慢**：先打开子地图，再进入专注模式；不要连续快速切换 21 张地图。
- **投影分辨率偏小**：收起知识库目录或地图检查栏，使用各模块的专注模式。
- **软件被关闭**：重新运行 `npm run demo:open`；异常重启恢复已通过自动测试。
- **搜索正在建索引**：直接从世界目录进入已知条目，不在台上执行重建索引。

## 禁止操作

- 不在正式案例上运行 `recording-world-demo.cjs`。
- 不删除、复制或批量重建正式世界。
- 不创建完整工程备份；当前用户备份目录已经很大。
- 不展示 API Key、资源文件路径、数据库路径或开发者秘密字段。
- 不把候选包描述为已签名正式稳定版。

## 展演后

1. 等顶栏显示“已保存到 SQLite”后正常退出。
2. 记录现场发现，不在观众面前直接改正式数据。
3. 如需录制自动建世界过程，必须先设置独立目录：

```powershell
$env:WORLDCRAFT_DEMO_USER_DATA_DIR="$env:LOCALAPPDATA\worldcraft-codex-recording-demo"
npm run dev
node scripts/recording-world-demo.cjs
```
