# Worldcraft Codex 1.7.0-beta.2

## AI 写作室界面重构

- 将原有三栏写作室重构为资料列表与主工作区两栏，移除常驻右侧控制栏。
- 写作会话按“文稿、审校、版本”切换，一次只显示当前任务。
- 长期记忆按“事实、来源、关系、冲突”切换，来源与关系不再和事实编辑同时堆叠。
- 创作设定、策划提纲和本轮召回记忆改为按需展开，正文保持第一视觉重点。
- 左侧增加会话与记忆搜索，状态、冲突数量和版本数量在紧凑列表中显示。
- 精确定位建议会自动切回正文并选中原句；应用修改后仍可继续保存检查点。
- 记忆状态合并为单一选择器，冲突只在相关记忆中显示，并提供清晰的保留与忽略操作。

## 验证

- 覆盖 1440 像素桌面窗口和 1100×780 窄窗口，页面无横向溢出。
- Electron E2E 覆盖深度写作、页签切换、精确定位、来源查看、事实确认、冲突解决与重启持久化。
- 数据 schema 保持为 13，本次更新不改写现有项目数据。
