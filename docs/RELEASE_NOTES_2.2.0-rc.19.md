# Worldcraft Codex 2.2.0-rc.19

## 长篇文稿核心

- 新增独立“书籍 -> 卷 -> 章 -> 场景”文稿树，支持新建、拖动排序、拆分、合并、层级字数与状态统计。
- 章节和场景正文支持专注全屏编辑；对象历史可查看版本差异并恢复，自动保存继续使用 SQLite 对象级增量写入。
- 旧叙事里程碑数据可迁移为文稿结构，制作计划与小说正文从此保持独立。

## 稳定引用

- 富文本引用升级为携带对象 ID、类型、世界 ID 与显示标签的编辑器节点，目标改名后引用不会断开。
- 旧 `[[标题]]` 继续兼容；项目检查新增重名、失效和跨世界引用诊断，并可跳回来源字段。
- 文稿书籍、卷、章和场景接入全局搜索、反向引用、发布净化和 `.wcodex` ID 重映射。

## AI 与一致性

- AI 上下文按全书、卷、章和场景分层，优先使用作者确认事实、未闭合线索和相邻场景摘要，再按需加入正文。
- 长文生成支持 OpenAI-compatible SSE 流式返回与主动取消；取消后保留已经生成的文本，审校建议仍按精确原句定位。
- 一致性扫描新增人物知识状态、章节时间、伏笔未回收和回收早于提出四类规则。

## 存储与兼容

- 工作区升级到 schema 17，新增六组文稿集合、对象历史和 FTS 索引；从 schema 16 升级前仍创建一致性副本。
- 文稿、线索和人物知识记录完整进入 SQLite、快速快照、完整工程备份、`.wcodex` 和旧 JSON 兼容路径。
- 发布 JSON/Markdown 会过滤开发备注、秘密引用和内部线索账本，不把作者私有规划误当公开正文。

## 验证

- 类型检查、生产构建、领域、AI、引用、发布、SQLite、迁移、工程包、压力和 1 万条目性能门禁全部通过。
- Electron 冒烟通过 402 项断言与 3 次启动，覆盖文稿创建、正文保存、稳定引用、专注模式、正常退出和异常退出恢复。
- Windows x64 发行物、哈希和打包后验证结果见 `validation/G6_MANUSCRIPT_RELEASE_VALIDATION.md`。
