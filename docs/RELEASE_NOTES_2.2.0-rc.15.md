# Worldcraft Codex 2.2.0-rc.15

## 地图 2.0：比例尺与坐标网格

- 地图设置新增横向实际跨度和距离单位，可选择千米、英里、米、英尺、里或自定义单位；纵向距离会根据底图宽高比自动换算。
- 画布左下角新增动态比例尺，随缩放级别自动选择易读刻度，并同步使用地图当前单位。
- 坐标网格支持显示、坐标标签、列数、颜色与透明度设置；行数根据底图比例自动推导，保持格网尺寸一致。
- 网格吸附可作用于新建标记、右键落点、单个或批量拖动、区域绘制、顶点编辑和边中点插入；批量移动会保持对象间相对位置。

## 测距与路线行程

- 工具栏新增测距模式，可在画布、标记、聚合标记和区域标签之间选择起止点，并实时显示地图实际距离。
- 地图右键菜单可直接“从这里开始测距”，顶部状态栏和画布标注会同步展示当前结果，可一键清除后继续测量。
- 路线检查器新增步行、骑乘、载具、航行、飞行和自定义行程方式，以及速度和每日行进时数设置。
- 路线目录和检查器会显示实际总里程、预计耗时与天数；分段明细逐段列出起止点、距离和时间。
- 区域边界周长和 Markdown 导出改用地图校准后的实际单位；地图导出同时包含跨度、网格、路线方式、速度、总里程、行程时间和分段里程。

## 交互与可靠性

- 地图全屏工作区在紧凑桌面宽度下采用更窄的目录与检查器，模式切换、颜色控件、路线统计和分段列表不会挤压画布或产生横向溢出。
- 修复事务式 AI 写入与旧自动保存快照并发时，较早快照可能在新内容之后落盘的问题；AI 行内应用、撤销、项目操作和操作撤销现在会在提交前取消待执行的旧快照，并在失败时恢复自动保存重试。
- 旧项目在加载时会补全地图比例尺、网格和路线行程默认值，不改变数据库 schema，也不重写既有地图、标记、区域或路线 ID。
