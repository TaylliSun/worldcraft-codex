# Worldcraft Codex 2.2.0-rc.6

## 星体关系图

- 星图条目改为 Obsidian 风格圆形节点，图标、标题和关系数量保持在星体内部。
- 从当前核心执行最短路径分层：直接关系进入一度环，间接关系依次进入二度、三度及更外层轨道。
- 每条星球环显示明确的关系度标签；隐藏某类关系或更换核心后会即时重新计算层级。
- 轨道使用完整圆环，半径会根据同层节点数量自动扩大，避免星体相互重叠。
- 整套星系围绕核心缓慢运行，连线、方向箭头和标签同步移动，节点文字反向旋转并始终保持水平。
- 新增运行 / 暂停控制；悬停或键盘聚焦节点与连线时自动暂停，并遵循系统“减少动态效果”设置。
- 关系强度继续控制连线粗细，关系度只负责轨道远近，两个概念保持独立。

## 验证

- Next.js 生产构建与 TypeScript 检查通过。
- Electron 桌面回归通过 `126` 项断言，新增验证一度 / 二度轨道、圆形节点、真实运行动画和暂停控制。
- 数据库 schema 保持 `16`，可直接读取此前项目。
