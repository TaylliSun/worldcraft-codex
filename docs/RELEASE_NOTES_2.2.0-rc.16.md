# Worldcraft Codex 2.2.0-rc.16

## AI 项目操作：地图与叙事制作

- 内置 AI 项目操作新增地图、地图图层、地图标记组、地图标记、地图路线和叙事里程碑六类目标，可与条目、任务、剧情、关系和时间线在同一事务中创建、修改或删除。
- 同批创建的对象可通过短引用互相连接；AI 可以一次建立角色、任务、场景、地图、区域、标记、路线、时间点和章节里程碑，不需要作者逐项确认。
- 新建地图会自动获得可用的默认图层；AI 也可建立专用图层和标记组，并让路线停靠点、区域引用与里程碑关联指向同批创建的对象。
- 地图区域作为地图的结构化子数据操作，支持标题、类型、颜色、透明度、边界点和跨模块引用；坐标统一使用 0 至 100 的地图百分比。
- AI 上下文新增地图结构、标记、路线和叙事里程碑摘要，同时继续排除秘密模板字段、本地地图图片路径和制作备注。

## 原子校验与安全边界

- 写入前统一运行任务循环、剧情节点、时间线、地图归属、图层与标记组、路线停靠点、区域边界、项目引用和里程碑依赖校验；任一错误都会阻止整批写入。
- 地图绑定对象不能跨世界创建或移动；地图图片路径不在 AI 字段白名单中，模型无法改写本地资源位置。
- 删除地图、标记或制作对象时，必须在同批次清理全部依赖；遗漏路线停靠点、区域引用或里程碑引用会被原子校验拒绝。
- 每次执行前仍自动创建独立检查点，审计保存完整前后状态；作者后续未修改对象时可一键完整撤销，已发生手工修改时停止覆盖式撤销。
- 旧 AI 操作记录继续兼容；导入项目时地图、图层、标记组、标记、路线和里程碑审计 ID 会随对象一起重映射。数据库 schema 保持 `16`。

## 审计与界面

- AI 项目操作面板新增地图与制作对象计数，示例任务直接体现地图标记、调查路线和章节里程碑工作流。
- 最近操作列表显示所有显式变更和新地图自动生成的默认图层，并保持紧凑可滚动布局。
- 点击审计记录可精确打开受影响的地图、图层、标记组、标记、路线或叙事里程碑；地图内部结构会切换到正确模式和检查器。
- 1440 与 1100 像素桌面宽度下，命令区、七类上下文计数、十五项审计列表和撤销入口均无横向溢出。
