# Worldcraft Codex 2.2.0-rc.2

## 新增

- 剧情工作区新增“正文”模式，可按卷 / 幕管理章节并持续编写小说式长篇正文。
- 章节支持大纲、创作备注、字数统计、排序、资源插图、双向链接和专注全屏编辑。
- 章节正文接入内嵌 AI，可续写、改写、扩写、检查一致性并保留可撤销记录。
- 任务依赖图与任务线分支图新增全窗口查看，支持 `Esc` 或关闭按钮退出。

## 数据与发布

- 章节正文随 SQLite 自动保存、备份、项目文件和 JSON / Markdown 导出持久化。
- 发布导出继续净化秘密正文块与开发者备注。
- 数据库 schema 保持 `16`，可直接读取 `2.2.0-rc.1` 项目。

## 验证

- Next.js 生产构建通过。
- Electron 桌面回归通过 `110` 项断言，覆盖章节保存、正文专注模式、两种任务图全屏以及正常 / 异常重启恢复。
- 迁移矩阵、项目文件往返、SQLite 存储、发布隐私和 AI 字段修改测试通过。
