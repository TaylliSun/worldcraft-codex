# Worldcraft Codex 2.2.0-rc.10

## 关系册

- 原“脉络”连线图改为结构化“关系册”，避免国家、角色、地点、物品和组织增多后产生交叉线与节点堆叠。
- 关系按敌对、控制、位置、路线等类型分组，每一行明确显示来源条目、关系名称、方向、强度和目标条目。
- 点击行两端可切换当前核心条目，双击可打开对应条目；点击中间关系可直接在右侧检查器中查看和编辑。
- 支持“当前直接关联 / 二度上下文 / 全部关系”三种范围；上下文中的间接关系会降低视觉权重。
- 每种关系默认显示最多 `8` 条，并提供继续显示与收起操作，保证大型世界仍可快速浏览。
- 关系册移除了缩放、拖动画布和暂停等不适合列表阅读的控制；这些空间探索能力继续保留在“星图”视图中。

## 星图

- “星图”继续用于围绕当前条目探索关系，按关系强度分配不同轨道。
- 保留缩放、适配、定位、拖动、暂停和关系类型筛选，与关系册形成“精确查阅 / 空间探索”两种互补工作方式。

## 视觉验证

- 已检查嵌入式关系册、全屏直接关系、全屏二度上下文和星图截图。
- 关系分组、长文本、选中态、间接关系弱化、右侧检查器和窄屏重排均无重叠或遮挡。
