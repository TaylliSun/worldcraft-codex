# Worldcraft Codex 2.2.0-rc.7

## 强度星图

- 修正星图分环语义：围绕当前核心的直接关系按强度 `5` 至 `1` 从近到远进入不同轨道，不再把不同强度的条目挤在同一环上。
- 每条直接关系轨道显示强度与亲密度标签，星体内部同步显示对应强度；强度颜色同时用于轨道和节点光环。
- 新增“仅直接关系 / 展开二度 / 展开三度”范围选择器；间接关系使用独立的中性轨道和明确标签，不冒充核心的直接关系强度。
- 关系范围变化后自动重新适配缩放，新增外环不会被画布底部裁切。

## UI / UX

- 星图改为深色天体画布，保留轻量网格；轨道、节点类型、关系连线和核心星体形成更清楚的视觉层级。
- 圆形条目增加类型图标色与强度光环，关系标签使用适配暗色画布的底色，提高暂停阅读时的辨识度。
- 收紧星图安全边距，在完整显示外环和标签的前提下提高节点可读尺寸。
- 窄窗口下重新排列关系图工具栏，范围选择器与视图、缩放控制保持可操作。

## 验证

- Next.js 生产构建与 TypeScript 检查通过。
- Electron 桌面回归通过 `131` 项断言，固定覆盖艾琳的强度 5 / 强度 4 分环、间接关系展开、自动适配、圆形节点、运行动画和暂停控制。
- 发布诊断通过 `28` 项断言；便携版冷启动通过 `11` 项断言，SQLite `quick_check` 为 `ok`，数据库 schema 保持 `16`。
