# 中国上古神话史：长线制作目标

## 项目定位

工作名为“中国上古神话史”，内容范围实际覆盖“上古神话核心，以及它在佛教、道教、儒家礼制和民间信仰中的后世演变”。项目不会把各传统拼成一套从古至今从未变化的统一神谱，而是同时呈现神话叙事、文献记载、宗教制度与民间合流。

第一公开版目标：建立一套可追溯、可检索、可画关系图、可按年代阅读，也能服务小说和游戏创作的中文神话知识库。

## 内容边界

1. 古籍原文单独呈现，不与今译、解释或原创剧情混排。
2. 今译、导读和百科叙述由 Worldcraft Codex 依据原典重新编写，不复制第三方 Wiki 或现代译文。
3. 项目补写的故事统一标注：“Worldcraft Codex 原创改编，不属于古籍原文或传统传说。”
4. 公开 Wiki 不保存外部链接；出处使用“书名、篇卷、章节、版本说明”的内部书目格式。
5. 佛教、道教、儒家礼制、地方信仰分别建类。发生吸收、改称或合祀时，用关系和年代说明，不直接合并页面。
6. 对同一身份存在争议时，保留多个条目或多个解释，并标记“明确、主流说法、存疑、后世附会”四级可信度。

## 知识结构

一级目录：

- 原初宇宙与天地秩序
- 上古神祇、帝王与英雄
- 山川、星辰与自然神
- 道教神谱与神职体系
- 汉传佛教佛、菩萨、护法与祖师
- 儒家礼制、圣贤与国家祀典
- 民间信仰与地方神
- 三教交涉、同神异名与合祀
- 原典文献库
- 原创改编区

核心条目模板：

- 神祇与人物：名称、别称、传统归属、最早记载、活跃年代、神职、形象、法器、眷属、祭祀、地域差异、争议、创作使用边界。
- 文献与传本：书名、成书层、版本、卷篇、原文位置、相关人物、异文与可信度。
- 神职与天界机构：所属体系、职掌、上级、下属、形成年代、不同派别说法。
- 祭祀与信仰：主祀、配祀、礼仪、地域、制度年代、民间变化。
- 神话事件：叙事年代、最早文献年代、参与者、地点、因果、版本差异。

## 关系模型

每条关系必须包含关系类型、适用年代、证据出处、可信度和说明。主要类型包括：

- 血缘、婚姻、师承、创造与化生
- 君臣、神职隶属、护持、统辖与敌对
- 化身、分灵、封号承继、追封与敕封
- 同名异神、异名同神、后世合流与争议对应
- 同祀、配祀、庙宇共存、文本共现
- 文化吸收、职能替代与图像借用

“同一位神”和“后来被视作同一位神”必须使用不同关系，不能用别名直接覆盖。

## 四条时间轴

1. 神话叙事轴：开天、造化、诸神世系、洪水、战争、圣王与文明起源。
2. 文献证据轴：先秦材料、两汉整理、魏晋六朝增衍、隋唐以后文献见证。
3. 宗教制度轴：国家祀典、道教教团与神谱形成、佛教传入与汉化、文庙和配祀制度。
4. 信仰演变轴：封号变化、地方神全国化、三教合流、小说戏曲和民俗再塑。

神话事件使用相对年代；历史事件使用可考纪年。两者不得共用一套看似精确的公元年份。

## 视觉目标

- 神祇与人物使用透明背景独立图，避免把后世小说造型冒充早期图像。
- 每张图记录“参考时代、服饰依据、宗教传统、是否为项目艺术改编”。
- 宗教图像优先尊重经典形制；存在多种传统时制作版本组，不强行选定唯一标准像。
- 地图按神话空间、历史传播和信仰地理分层，不把想象地名伪装成现代经纬度。

## 中国佛教完整知识库

原有汉传佛教阶段提供的是 180 篇核心导览，不等于佛教人物、经典和历史材料已经收齐。完整知识库把范围扩展到汉传佛教主体，并分别建立藏传佛教与中国南传上座部佛教分区。硬目标为不少于 1000 篇佛教直属条目、500 位经过消歧的佛菩萨、弟子、护法、译师、祖师与历史人物、300 部经律论和注疏、3000 条带证据关系、220 个时间事件。

内容按以下边界整理：

- 同一经典的梵本、藏译、不同汉译和后世分科分别记录，不能拼成一份没有版本边界的“标准全文”。
- 古代经文与古注可以作短句引用；白话释义、条目正文和创作提示均由项目重新撰写，不复制现代受版权保护的译文。
- 佛典神圣叙事、可考译经活动、宗派祖统、寺院仪轨和现代研究结论分层呈现。
- 传统归名、现代学术争议和项目原创改编分别标示；公开正文不保存外部网址。
- 藏传与南传材料按各自语言、谱系和制度建立入口，不用汉传名相强行覆盖。

## 编辑语气

百科正文以清楚、克制、有具体证据的中文为准。避免“古老而神秘”“命运的齿轮”“不为人知的秘密”“最终揭开真相”等空泛套话。创作建议只在原创改编区出现，并写清它与传统材料的分界。
