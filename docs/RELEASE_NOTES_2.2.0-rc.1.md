# Worldcraft Codex 2.2.0-rc.1

## 首次启动与项目起步

- 空数据库首先提供“游戏叙事”“RPG 战役”“视觉小说”“开放世界任务”四类起步包，不展示宣传页。
- 每个起步包直接创建可编辑条目、至少两步任务、剧情场景、变量和叙事里程碑，并在一次 SQLite 保存后进入创作台。
- 从世界设置创建新世界也使用同一流程；项目类型可取消，首次初始化不可意外跳过。

## 大型项目与桌面交互

- 项目分类默认折叠，折叠分支不创建条目 DOM；展开后每批加载 120 个条目，并保留当前选中对象。
- 侧栏搜索使用延迟值，1 万条目性能门禁覆盖保存、冷加载、引用索引、筛选、对象切换、增量保存和全文检索。
- 统一创建、分类、全局搜索、字段级 AI 和起步包弹窗共用焦点管理：初始聚焦、Tab 环回、Esc 关闭和焦点归还。
- 中文输入法组合态不会误触发 Enter 提交、Esc 关闭或 `Ctrl/Cmd+K` 全局搜索。
- 世界设置选择世界或创建新世界后会立即收起并归还焦点，不再遮挡 AI 工作台控件。

## 可靠性与升级

- 修复有效 `.wcodex.json` 备份在备份列表中被误标为损坏的问题，并加入 Electron 永久回归断言。
- schema 保持 `16`；支持从 `2.1.0-beta.1` 覆盖安装，世界、条目 ID、内容、SQLite 和备份均保留。
- NSIS 静默卸载删除应用目录但保留用户数据库和备份。
- 24 个测试脚本、TypeScript、Next.js 生产构建、解包版、便携版和安装升级链路全部通过。

## 范围与限制

- 本版本是 Windows x64 Release Candidate，不包含社区、插件市场、实时多人协作、云同步或游戏引擎专用导出。
- 当前发行物没有可信的公开代码签名证书，Windows SmartScreen 可能显示未知发布者。
- AI 模型仍可能产生错误；来源、一致性预检、检查点与撤销降低风险，但不能替代作者审阅。
