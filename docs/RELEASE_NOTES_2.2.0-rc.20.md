# Worldcraft Codex 2.2.0-rc.20

发布日期：2026-07-16
状态：Windows x64 未签名候选版，不是正式公开稳定版。

## 本次补全

- 长篇工作台新增正式出版面板，可按全书、单卷或自选章节生成 DOCX、PDF 和 EPUB，并配置目录、封面、摘要、场景正文、A4/Letter 与两套书稿密度。
- 章节和场景新增批注线程与修订建议，可从正文选区建立引用、回复、接受、拒绝或解决；接受时只替换仍然匹配的原句。
- 新增每日目标、今日净增、连续写作、14 天节奏与全书进度，统计和批注随 SQLite、备份与 `.wcodex` 保存，发布净化始终移除这些作者私有数据。
- AI 长期记忆新增完全本地且可解释的语义召回，显示来源、权威级别、相关度和命中理由，并允许按当前写作目标排除与恢复。
- 为 NSIS 安装版加入稳定/候选更新通道、启动检查偏好、显式下载、下载进度和重启安装；便携版保持手动更新。
- NSIS 改为每用户单击安装并关闭安装后自动启动，降低覆盖升级时的进程冲突；卸载继续保留用户数据，需要自定义位置时可使用便携版。
- 下载与重启安装前检查系统盘可用空间，低于 2 GiB 时保留现有版本并给出可操作提示。
- 安装更新前冲刷自动保存、保存 Worker 和 SQLite，更新错误只显示脱敏状态，失败不会删除当前项目。
- 增加公开发行输入门禁、首启条款接受、隐私/支持链接和候选构建外部阻塞说明。
- 加固 Electron CSP、权限、导航、外链、IPC 与 fuses，启用 ASAR 完整性校验并关闭 RunAsNode、NODE_OPTIONS 和远程调试参数。
- 生成生产依赖第三方许可正文/inventory、CycloneDX SBOM、秘密与依赖扫描、SHA-256、签名状态、manifest 和构建来源。
- 增加 Windows 质量 CI、签名草稿发布流程和本地单命令发行门禁。

## 当前外部阻塞

当前候选版没有真实发行主体、代码签名证书、公开法律/支持页面或稳定/候选更新托管地址，因此 Windows 可能显示未知发布者，应用不会发起更新检查。正式公开前必须由实际发行者提供并审核这些输入，再使用 `npm run dist:public` 重新构建。

## 数据兼容

- SQLite schema 保持 17。
- NSIS 卸载默认保留用户数据。
- `.wcodex`、备份、资源、文稿、AI 会话与长期记忆格式保持兼容。
- 旧文稿会自动补齐空批注、每日目标和写作历史；无需升级数据库 schema。
- 社区、插件市场、云账号、遥测上传和游戏引擎集成不在本版本范围内。
