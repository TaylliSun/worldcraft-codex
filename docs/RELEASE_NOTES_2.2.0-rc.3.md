# Worldcraft Codex 2.2.0-rc.3

## 世界关系图

- 世界关系图新增全窗口查看，可用 `Esc` 或关闭按钮返回编辑页。
- 新增 60% 至 150% 缩放与当前条目定位控制。
- 同类型节点按焦点和关系数量排序，节点组垂直居中，减少交叉连线与无效空白。
- 聚焦条目时突出直接邻居与相关连线，保留其他节点作为可读背景。
- 统一有向关系箭头尺寸，避免高强度关系产生过大的箭头。

## 验证

- Next.js 生产构建与 TypeScript 检查通过。
- Electron 桌面回归通过 `113` 项断言，覆盖章节正文、任务图、关系图全屏、关系图缩放以及正常 / 异常重启恢复。
- 数据库 schema 保持 `16`，可直接读取此前项目。
