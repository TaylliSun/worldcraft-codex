# Worldcraft Codex 1.5.0-beta.1

本版本新增可选 AI 创作工具层，支持本地模型和使用 HTTPS 的第三方 OpenAI-compatible 服务。

## AI 工具

- 选择世界摘要、条目、任务线或剧情场景作为单次发送上下文。
- 提供摘要、润色、续写、角色深化、任务拆解和自定义指令。
- 生成结果先进入可编辑预览，可复制或明确追加到条目正文。
- 一致性发现可复用同一连接生成补充解释，核心规则仍完全离线运行。

## 安全边界

- AI 默认关闭，不进行后台请求。
- 本地服务只允许回环地址；第三方服务必须使用 HTTPS，禁止 URL 内嵌认证和重定向。
- API Key 使用 Windows 系统凭据加密保存，不进入项目、备份、导出、日志或诊断包。
- 模板秘密字段和任务开发者备注默认不进入创作上下文。
- 请求前显示上下文预览，AI 输出不会自动覆盖项目原稿。

第三方服务的计费、内容保留与隐私规则以对应服务商条款为准。
