# 公开发行检查表

## 身份与法律

- [ ] 真实法律主体已填写，品牌显示名没有冒充公司或个人。
- [ ] 证书 Subject 与 `WORLDCRAFT_CERTIFICATE_PUBLISHER` 完全匹配。
- [ ] 隐私政策、使用条款、支持与安全报告页面均为已发布 HTTPS 页面。
- [ ] 首启条款版本与本次发行一致，安装器展示正确法律摘要。
- [ ] 第三方许可清单没有未知许可证或空正文。
- [ ] 每用户单击安装、首次启动条款、便携版和卸载保留数据行为已在干净 Windows 用户上人工复核。
- [ ] `test:installer-package` 的干净安装、版本、注册表、静默卸载与清理全部通过。
- [ ] 系统盘空间低于 2 GiB 时更新被阻止，释放空间后可重试且现有版本不受影响。
- [ ] 便携版在有 2 GiB 临时空间的干净用户上完成冷启动；低空间限制已写入下载说明。

## 构建与供应链

- [ ] 在干净 Windows x64 环境执行 `npm ci` 与 `npm run release:gate`。
- [ ] 执行 `npm run dist:public`，两个 `.exe` 的 Authenticode 状态均为 `Valid`。
- [ ] `npm audit --omit=dev` 没有 high/critical 漏洞，秘密扫描无发现。
- [ ] CycloneDX SBOM、第三方 inventory、provenance、manifest 和 `SHA256SUMS.txt` 已生成并验证。
- [ ] 发布标签严格等于 `v<package.json version>`，工作流创建的是草稿而非自动公开版本。

## 安装与数据

- [ ] 干净用户首次安装、首启条款、项目创建和正常退出通过。
- [ ] 从上一支持版本覆盖升级后 schema 17、资源、备份、AI 记忆和凭据边界通过。
- [ ] 升级机械基线只存在于 `validation/baseline-release/`；已有正式版时改用上一签名正式安装包复核。
- [ ] 更新下载失败、安装失败和异常退出不会覆盖当前项目。
- [ ] 卸载默认保留用户数据；删除数据前已提示导出 `.wcodex` 与备份。
- [ ] 便携版冷启动和手动替换通过，界面不会声称支持自动更新。
- [ ] 打包工程往返使用临时 inspector 测试副本；发布原件仍由 fuse 校验确认 `nodeCliInspect` 为禁用。

## 托管与发布

- [ ] 稳定/候选使用独立目录；安装包和 blockmap 先上传，`latest.yml` 最后切换。
- [ ] 从远端重新下载并核对 SHA-256、签名 Subject、版本和文件大小。
- [ ] 用干净机器从远端源完成一次检查、下载、重启安装和失败回退演练。
- [ ] 已知限制、发布说明、支持入口和安全报告流程随发行物公开。
- [ ] 草稿 Release 经实际发行者复核后才转为公开。
