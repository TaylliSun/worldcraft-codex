# Worldcraft Codex 2.2.0-rc.14

## 地图 2.0：区域与领地

- 地图内容目录新增“区域”模式，可在领地、城区、生态区、危险区、任务区域和自定义范围之间分类管理。
- 区域绘制工具支持在画布上连续落点形成多边形；可完成、取消或撤回最后一个顶点，也可从地图右键菜单直接开始绘制。
- 选中区域后会在画布上显示顶点和边中点；可拖动顶点修改边界、点击中点插入顶点，并在至少保留三个顶点的前提下删除多余顶点。
- 区域检查器支持名称、类型、说明、颜色、填充透明度、显示状态、顶点锁定和叠放顺序。
- 锁定后区域仍可选择和查看，但不显示编辑把手；隐藏后画布和缩略图同步移除对应多边形。

## 剧情关联与空间统计

- 区域可关联角色、地点、组织、任务、剧情场景、时间点和地图标记，并进入项目级引用索引与反向引用检查。
- 区域检查器实时计算地图覆盖率和边界周长，画布标签以多边形中心点定位，缩略图同步呈现区域轮廓。
- Markdown 地图导出新增区域类型、面积、周长和说明，便于交接世界空间设定。
- 旧项目地图会在加载时补全空区域集合，不改变数据库 schema，也不重写既有地图、图层、标记或路线 ID。

## 地图工作区细节

- 四类地图内容以紧凑的两行切换器呈现；全屏目录在条目较少时保持从顶部连续排列，不再拉伸列表项。
- 切换标记、路线、区域、图层或地图后，右侧检查器自动回到顶部，避免继承上一个对象的滚动位置。
- 区域多边形位于地图底图之上、路线和标记之下，编辑把手保持固定屏幕尺寸，不会随缩放变得难以点击。
