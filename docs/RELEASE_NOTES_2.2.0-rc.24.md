# Worldcraft Codex 2.2.0-rc.24

`2.2.0-rc.24` 是 Windows x64 候选版。本版集中处理大型项目响应速度、无限地图导航、多主题一致性与键盘操作，使数千条目世界在演示和长期创作中更稳定、也更容易找到内容。

## 本版变化

- 全关系图谱改为 320、640、1200 个核心条目递进展示；大型图使用确定性快速布局，仍可搜索并定位全部条目。
- 关系册保持按关系类型逐组加载，打开图谱不再先计算全部节点的力导向布局。
- 无限地图缩略导航改用真实内容边界，地图外的图片、标记、区域和路线仍可看见并点击定位。
- 地图底图范围只作为坐标参考，不再限制图层图片的移动、缩放和旋转位置。
- 资料台账每次加载 120 行，支持继续展开与一键选择当前筛选的全部条目。
- 夜航主题修正 AI 状态、输入标签、空状态和禁用按钮的低对比度文字。
- 五套主题统一检查工作区正文与主操作对比度，并生成逐主题截图。
- 全局搜索补充 `Ctrl+K` 提示、组合框语义和键盘选择自动跟随滚动。

## 大型项目验证

- 完整候选发布门禁通过 45 个阶段，生产与构建依赖审计均为 0 个已知漏洞。
- 新增与私有开发仓库隔离的公开发行站，提供匿名可访问的主页、安装版、便携版、SHA-256、隐私说明、问题反馈和候选更新源，避免外部访问私有仓库时出现 404。
- 使用 2406 个设定条目和 3604 条关系的隔离项目执行桌面压力流程。
- 关系册约 0.6 秒打开，全关系图谱约 0.5 秒打开，扩展至 1200 节点约 1.0 秒。
- 资料台账约 1.8 秒打开，可全选 2406 条并定位到压力数据末端条目。
- 完整 Electron 桌面流程通过 537 项断言，覆盖正常退出、正常重启和异常退出恢复。
- 五套主题与夜航关键工作区视觉巡检通过，无大型错误白色表面或正文对比度退化。

## 兼容性与范围

- 数据 schema 保持 17，现有 `2.2.0-rc.23` 工程可直接打开，不需要迁移。
- `.wcodex` 工程包、SQLite 数据、资源目录与 AI 凭据边界不变。
- 当前仍为未签名候选版；Windows 可能显示未知发布者提示。
- 不包含社区、实时多人协作、插件市场和游戏引擎专用导出。
