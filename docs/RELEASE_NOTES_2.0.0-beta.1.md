# Worldcraft Codex 2.0.0-beta.1

## 统一关联

- 新增跨类型统一关联器，可搜索、筛选、多选、跳转或就地创建条目、任务、剧情、变量、地图、标记、路线、时间点、里程碑与关系。
- 在关联器中创建的对象会自动回写原地图标记或时间点，不需要离开当前流程重新选择。
- 条目与任务显示精确反向引用，包括来源对象、来源字段、引用角色和正文摘录；点击后直接打开来源并定位对应控件或文本。
- 项目检查复用同一引用索引，统一发现失效 ID、未解析 `[[双向链接]]` 和重名目标。

## 地图与时间线

- 地图标记可关联多个跨类型对象；新增图层、标记组、显示控制和图层锁定，未上传底图时仍可完整编辑。
- 时间点可关联多个角色、地点、阵营、任务、场景和其他项目对象。
- 日期支持精确、约略、未知、区间与自定义纪元，并保留原有数值排序和依赖环检测。

## 阅读与秘密隔离

- 条目新增干净阅读预览，可独立开关页眉、资料、侧栏和页脚。
- JSON、Markdown 与阅读预览共用发布净化边界，默认排除秘密对象、秘密字段、秘密正文块、开发备注、测试/审阅资料和 AI 私有记忆。
- `.wcodex.json` 完整项目文件与自动备份继续无损保存内部资料，发布格式不再被误作备份格式。

## 桌面质量

- 工作区 schema 升级到 `16`，兼容 schema 8 至 15 的自动迁移，并在迁移前创建保护副本。
- 顶级工作区切换后自动回到页首；自动保存完成后明确显示 SQLite 状态。
- Electron 冒烟测试通过 3 次启动与 64 项断言，覆盖精确回链、关联器内新建、重启持久化、地图图层、时间线日期、正常退出和异常重启。
- 全部领域、存储、压力、恢复、迁移与发布测试通过；迁移矩阵通过 8 条升级路径、120 项断言。

## 范围

- 本版本不包含公开社区、插件市场、实时多人协作、云同步或游戏引擎专用导出。
- 发行物为 Windows x64 Beta，尚未使用可信的公开代码签名证书，Windows SmartScreen 可能显示未知发布者。
