# Worldcraft Codex 2.2.0-rc.11

## 三种关系视图

- 关系工作台现在包含“关系册 / 星图 / 全关系图谱”三种独立视图，三者共用同一份关系数据。
- 关系册用于按类型精确查阅与编辑关系记录；星图用于围绕当前条目探索关系强度和间接层级。
- 新增全关系图谱，用于一次查看整个世界的实体和关系，包括当前没有关系的孤立条目。

## 全关系图谱

- 使用 `d3-force` 生成稳定的力导向拓扑，角色、组织、地点、事件、物品和笔记按类型形成可辨认分区。
- 当前核心及其直接关系保持清晰，间接网络降低视觉权重；搜索结果、当前选中关系和悬停对象可重新提亮。
- 可按关系强度显示全部关系、强度 2 以上、强度 3 以上或仅强关系；关系类型图例继续支持单独隐藏。
- 支持关系标签开关、缩放、自动适配、拖动画布和定位当前条目，并为大型图谱提供 `20%` 最小缩放。
- 点击节点可切换当前核心，双击可打开条目；点击或键盘选择连线可直接打开右侧关系检查器。
- 力导向计算设有迭代上限，关系筛选不会移除实体，避免大型世界因降噪而失去全局结构。
