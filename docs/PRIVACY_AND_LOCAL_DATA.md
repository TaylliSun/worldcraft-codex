# 隐私与本地数据

Worldcraft Codex 是本地优先桌面软件。项目正文、秘密字段、SQLite 数据库、备份和导入资源默认只保存在当前 Windows 用户的数据目录中。实际目录可在“检查”视图查看；开发版通常使用 `%APPDATA%\worldcraft-codex`，安装版通常使用 `%APPDATA%\Worldcraft Codex`。

## 保存内容

- `worldcraft-codex.sqlite`：项目主数据、对象历史和搜索索引。
- `backups/`：自动/手动快速数据快照、恢复前 JSON 保护副本，以及用户创建的完整 `.wcodex` 工程备份。
- `backups/migrations/`：升级 schema 前的 SQLite 保护副本。
- `backups/rollbacks/`：迁移回滚前的安全副本。
- `assets/`：用户导入的图片、音频和资料文件。
- `logs/worldcraft.log.jsonl`：启动和错误事件元数据。
- `credentials/ai-key.json`：由 Electron `safeStorage` 使用当前 Windows 用户凭据加密的 AI API Key；不包含明文。

AI 写作会话、字段级修改记录、长期记忆、结构化事实、来源摘录、记忆关系、提纲、正文、审校建议、写作轮次和 AI 项目操作审计属于项目内容，保存在 SQLite 中，也会进入数据快照和完整 `.wcodex` 工程包。它们不会进入安全发布导出或脱敏诊断包。

卸载 NSIS 安装版默认不会删除上述用户数据。删除前应先导出项目并保留备份。

## 网络行为

软件没有云同步、遥测、广告、社区或自动上传。公开安装版可按用户保留的偏好，从发行者配置的 HTTPS 地址检查版本清单并下载更新；请求只涉及正常的网络连接元数据和当前应用版本，不携带项目正文、资源、诊断、AI 密钥或用户标识。候选构建没有配置更新地址时不会发起更新请求，便携版不自动更新。

AI 默认关闭；只有用户启用连接并主动点击生成、解释或执行项目任务时，对应上下文才会发送到配置的模型服务。本地模型只允许回环地址，第三方 OpenAI-compatible 服务必须使用 HTTPS。

API Key 在渲染界面提交后由主进程系统加密保存，后续不会读回界面，也不会进入 SQLite 项目数据、`.wcodex`、旧 `.wcodex.json`、备份、Markdown/JSON 项目导出、日志或诊断包。AI 创作上下文默认排除模板秘密字段、正文秘密块与任务开发者备注；普通标题、摘要、正文、任务步骤或剧情对白仍可能包含用户自行写入的敏感信息，发送前应检查上下文预览。

编辑器内 AI 只在作者点击生成时发送当前字段或选区、界面列出的项目来源及召回记忆。作者可在发送前固定、降低优先级或排除来源；模型返回后，实际引用来源会单独显示。应用、撤销和一致性前后对比在本机执行，不会因此产生额外模型请求。

剧情写作室会把与当前目标相关的长期记忆、来源摘录、结构化事实、提纲和草稿片段发送给配置的模型服务。审校产生的新记忆默认标记为“草稿”，作者确认后才视为正式设定；置顶记忆会优先进入后续写作上下文，已停用记忆不会发送。

AI 项目操作会自动发送当前世界中条目、任务、剧情、关系和时间线的精简结构上下文，以便模型使用现有对象 ID 建立关联。该上下文包含标题、摘要、结构化节点和关联 ID，不包含条目正文、模板自定义数据、模板秘密字段或任务开发者备注。模型返回的命令会经过本地白名单与完整性校验，再由单次事务直接写入，不会逐项弹出确认框。

## 诊断包

“导出诊断包”只包含应用/系统版本、SQLite 检查结果、对象数量、备份和资源数量、迁移摘要及脱敏事件名称。它不包含项目正文、标题、秘密字段、对象 ID、文件路径、AI 连接设置或密钥。

## 导出边界

- `.wcodex` 工程包、旧 `.wcodex.json` 和 `backups/` 内的备份用于继续编辑与灾难恢复，完整保留正文、秘密字段、开发备注、测试资料和 AI 私有记忆，不应公开发送。
- `.wcodex` 与完整工程备份额外包含图片、音频和资料文件；快速数据快照不包含这些二进制资源。
- 普通 JSON、Markdown 和应用内阅读预览属于安全发布视图，默认移除秘密条目、秘密模板字段、秘密正文块、开发备注、测试/审阅资料和 AI 私有记忆，并清理指向已移除秘密对象的引用。
- API Key 不进入上述任何项目文件、备份、发布导出或诊断包。

安全发布是防误泄漏的默认边界，不替代作者最终审阅。普通标题、摘要或正文中自行写入但未标记为秘密的敏感信息仍会进入 JSON/Markdown 发布导出。
