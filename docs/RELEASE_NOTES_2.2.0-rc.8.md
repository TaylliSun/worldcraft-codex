# Worldcraft Codex 2.2.0-rc.8

## 脉络视图

- 重构世界关系“脉络”画布，移除笨重的整列色块与密集小网格，改为轻网格、类型轨道和清晰的关系流向。
- 角色、组织、地点等类型使用独立顶部色线、图标与数量标记；轨道中轴帮助快速比较同类条目。
- 节点改为紧凑条目样式，统一边距与阴影，并通过类型图标、选中底色和细小关系接点区分状态。
- 没有关系的条目不再显示接点，避免产生可以拖线的错误暗示。
- 关系连线使用圆角端点，标签与当前关系保持清楚层级；嵌入视图和全屏视图使用同一套布局逻辑。

## 操作简化

- 脉络模式不再显示“关系范围”和“星体运行”两个星图专属控件，工具栏只保留当前可执行操作。
- 调整脉络节点尺寸、列间距与自动适配计算，信息更紧凑，关系标签仍有足够空间。
- 星图的强度分环、二度 / 三度展开、自动适配与运行动画保持不变。

## 验证

- Next.js 生产构建与 TypeScript 检查通过。
- Electron 桌面回归通过 `133` 项断言，新增覆盖脉络模式专属工具栏状态，并生成嵌入与全屏视觉截图。
- 发布诊断通过 `28` 项断言；便携版冷启动通过 `11` 项断言，SQLite `quick_check` 为 `ok`，数据库 schema 保持 `16`。
