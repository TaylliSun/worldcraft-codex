# Worldcraft Codex 1.7.0-beta.1

## 叙事记忆引擎

- AI 审校会把后续必须记住的内容拆成主语、属性、值和生效范围，同时保留自然语言说明。
- 每条自动记忆记录精确来源摘录、项目目标和写作会话；作者可从记忆直接回到项目来源。
- 记忆拥有草稿、作者确认和已停用三种事实状态。已停用项保留在项目中，但不会进入后续 AI 上下文。
- 支持作者置顶、核验时间、标签，以及支持、矛盾、依赖、取代和相关五类记忆关系。

## 召回与冲突

- 写作前按作者置顶、确认状态、项目目标、结构化事实和内容关键词召回记忆。
- 写作室显示实际召回项、召回依据和相关度，便于作者确认 AI 获得了哪些上下文。
- 同一主体、属性和生效范围出现不同事实值时自动提示；作者声明的矛盾关系也会进入冲突中心。
- 作者可选择保留其中一项，另一项会标记为已停用并建立取代关系；也可忽略有意保留的差异。

## 数据与兼容

- 项目数据升级为 schema 13，升级前自动创建 SQLite 迁移保护副本。
- 旧版文本记忆保持原有对象 ID 和内容，并自动补充为可追溯的旧版项目来源。
- 记忆事实、来源、关系、状态和冲突忽略决定进入对象历史、项目备份和完整项目导出，不进入脱敏诊断包。

AI 长期记忆能够显著降低跨章节遗忘，但不能保证第三方模型永不犯错。关键设定仍应由作者确认，结构化冲突提示也需要作者做最终判断。
