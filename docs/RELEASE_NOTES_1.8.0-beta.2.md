# Worldcraft Codex 1.8.0-beta.2

## 简化编辑界面

- 全局导航改为 64px 图标栏，知识库、任务、剧情、制作、关系、地图、时间线与 AI 保持一步可达，低频工具收进“更多工具”。
- 世界名称、保存状态、搜索和世界设置收进紧凑顶栏；世界简介、世界切换与项目统计不再长期占用主画布。
- 知识库采用可收起条目抽屉、单一编辑画布和默认隐藏检查侧栏，左右辅助区可独立开关。
- 条目编辑分为“正文 / 资料 / 设置”，默认进入正文，模板资料和元数据按需显示。

## 专注写作

- 摘要、模板长文本和富文本正文均支持一键全屏编写。
- 富文本专注模式保留格式、表格、图片、双向链接、角色提及、标签与撤销工具。
- 所有专注模式支持 `Esc` 返回，保存逻辑与版本历史保持不变。

## 验证

- TypeScript 类型检查与 Next.js 生产构建通过。
- Electron 冒烟测试通过 3 次启动、51 项断言，覆盖正常退出、异常重启、AI 项目操作、保存队列和新导航。
- 已验证 1424×901 与 1024×761 客户区；默认编辑、资料长文本、左右抽屉及两种专注模式均无页面级横向溢出。
