# Worldcraft Codex 2.2.0-rc.13

## 地图 2.0：直接编排

- 地图工具栏新增手形平移、框选标记和路线绘制三种明确的画布工具，保持查看、批量整理和路线创作之间的操作边界。
- 可使用框选或 `Ctrl` / `Shift` 组合选择多个标记；当前主选标记继续显示完整检查器，其余选中标记保持清晰高亮。
- 多个可编辑标记可以一起拖动或使用方向键微调，锁定图层或标记组中的对象会自动排除，避免批量误移动。
- 批量位移只生成一个历史动作，可一次撤销或重做；批量条还可将选中标记移动到指定图层或设置标记组。

## 画布快捷创建

- 在地图空白位置右键可原地创建标记、创建标记并开始路线，或将画布定位到该坐标。
- 在现有标记上右键可加入或移出多选、加入或移出当前路线、从该标记新建路线，以及快速定位。
- 快捷菜单会保持在画布可视范围内，打开后自动聚焦首个可用命令，并支持方向键、`Home`、`End` 与 `Esc`。

## 路线绘制与编辑

- 路线绘制工具允许依次点击地图标记形成有序路线，关联线和停靠点会立即更新。
- 当前路线在画布上显示停靠序号；点击序号可移除该站，工具条可撤回最后一站或结束绘制。
- 绘制期间按 `Backspace` 撤回最后一个停靠点，按 `Enter` 完成路线，右键标记可随时切换加入或移除状态。
- 原有路线检查器中的名称、状态、颜色、说明、停靠点详情和排序能力继续保留。
