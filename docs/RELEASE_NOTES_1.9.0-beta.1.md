# Worldcraft Codex 1.9.0-beta.1

## 创作骨架

- 知识库升级为多层分类项目树，分类包含父级、顺序、图标、颜色和说明，支持至少五层嵌套、折叠和拖放。
- 条目拥有稳定的分类与同级顺序；旧项目首次打开时自动迁移到 schema 15，不改写原对象 ID、模板或引用。
- 任务线和剧情场景保留为项目树中的固定顶层入口，不强行伪装成知识库文章。

## 创建与导航

- 新增统一创建面板，可一次选择角色、地点、阵营、事件、物品、笔记、任务线或剧情场景，并指定名称、模板、分类和可见性。
- 新增面包屑、最近打开、前进/后退和“在项目树中定位”，折叠项目树后正文占据主要画布。
- 摘要、正文与模板长文本继续支持独立全屏专注模式，按 `Esc` 返回。

## 保存与恢复

- 自动保存状态收敛为保存中、已保存和失败重试；桌面版明确显示数据已写入 SQLite。
- 编辑期间维护短周期恢复草稿，意外刷新或关闭发生在自动保存前时可恢复未完成内容。
- 分类、条目顺序和 AI 新建对象参与同一持久化模型；修复层级迁移后 AI 安全撤销误判作者修改的问题。

## 范围

- 本版本不包含公开社区、插件市场、实时多人协作或游戏引擎专用导出。
- 仍为 Windows x64 Beta，发行物未使用可信代码签名证书。

## 验证

- TypeScript 类型检查、Next.js 生产构建、schema 迁移矩阵和全部既有领域测试通过。
- Electron 冒烟测试通过 3 次启动、51 项断言，覆盖正常退出、异常重启、保存队列、AI 跨模块操作及完整撤销。
- 实测 1280×720 与 390×844；项目树、统一创建面板和正文编辑区无页面级横向溢出。
